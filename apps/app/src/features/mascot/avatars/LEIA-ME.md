# Mascotes

Definições no formato do [open-bot-avatar](https://github.com/DominikScholz/open-bot-avatar)
(contorno SVG + posição dos olhos), copiadas de `open-bot-avatar/arquivos mascotes/`.
O renderizador é o pacote `open-bot-avatar` (MIT).

`gatinho.json` é o `gato-de-laco-cabeca.json` original com `id` e nome trocados, porque o
original repetia o `id` do `gato-de-laco.json`.

Para adicionar um mascote: coloque o JSON aqui e inclua-o em `../mascots.ts` com uma cor e um
bordão. Ele é validado ao carregar.
